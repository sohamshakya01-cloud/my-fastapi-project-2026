# Task Management API

A REST API built using FastAPI for managing tasks.

## Features

- Create tasks
- View all tasks
- View a task by ID
- Update tasks
- Delete tasks
- JSON-based data storage

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic

## Installation

Clone the repository:

    git clone https://github.com/sohamshakya01-cloud/my-fastapi-project-2026.git

Navigate to the project:

    cd task-management-api

Create virtual environment:

    python -m venv venv

Activate virtual environment (Windows):

    venv\Scripts\activate

Install dependencies:

    pip install -r requirement.txt

Run the application:

    uvicorn main:app --reload
